1. `png/01-ai-health-closed-loop.png`：AI 驱动的个人健康行动闭环，适合放在项目背景、整体方案或 AI 核心作用部分。

同名 `.svg` 为可编辑矢量源文件；Word 排版优先使用 1600×900 PNG。
