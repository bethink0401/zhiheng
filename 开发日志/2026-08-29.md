## 问题与风险

- 本轮没有读取或使用用户真实 DeepSeek 密钥，也没有发送真实健康数据；白底气泡与显示加粗会作用于已有回复，结构化鼓励语只会出现在更新版本生成的新回复中，旧历史不会被伪造补写。
- 模型具体措辞仍会随问题和供应商输出变化，但新响应 Schema 已要求鼓励字段，客户端同时保留不改写原回答的重点显示兜底。
- 个人 Keychain 密钥在当前 Debug 真机版本中的实时新回答语气，仍需用户安装更新构建后发送一个新问题确认；Release 继续不包含个人密钥直连。
- 优先级变更：原唯一下一步为 S07-02，用户本轮明确要求先做 AI 流式输出并开始微计划。选择先完成 S12-16，再进入 S10 的第一个可用闭环；不改变 CareKitStore 独占计划执行事实、一次只运行一个低风险计划和最终结构化 AI 校验等既有边界。
- DeepSeek 官方 Responses API 的流以 SSE `response.output_text.delta` 返回，并以 `response.completed`、`response.incomplete` 或 `response.failed` 结束，不使用 `[DONE]`。结构化 JSON 会随文本增量到达，客户端必须只提取允许展示的正文，不能把 JSON 语法直接显示给用户。
- 本轮没有读取或使用用户真实 DeepSeek 密钥，也没有上传真实健康数据；真实 Keychain 直连的 SSE 速度和网络稳定性仍需用户安装更新版本后在自己的 iPhone 上发送一个新问题验证。
- 当前微计划是第一个可执行闭环，不等于 S10 全部完成：暂停/恢复、困难度、可选反馈、基线快照与结束评估仍分别保留在后续任务中。
- 本轮趋势卡已能显示计划相关客观指标及 CareKit 完成率，但尚未包含主观感受变化、干扰事件和正式的计划结束评估，因此 S10-09～S10-11 不标记完成。
- 模拟器视觉验收使用明确标注的演示健康数据；真实 Apple Health 数据下的计划趋势、不同来源组合和真机长周期表现，仍需用户在自己的 iPhone 上完成计划后观察。
