### 2. 视频基础参数规范
- **建议成片时长**：**3分45秒**（控制在 3分30秒 ~ 4分钟黄金区间，节奏紧凑、信息饱满）。
- **分辨率与帧率**：1920×1080 (1080P) 或 3840×2160 (4K)，**60 fps**（高帧率体现 iOS 与 SwiftUI 丝滑交互）。
- **画面构图**：16:9 横屏，采用“真机实拍/环境实景 + 手机高保真无损录屏 + 动态信息标注卡（HUD）”三合一画中画。
- **声音与配乐**：
  - 旁白：沉稳、专业、有温度的青年科技旁白（可使用高品质 AI 拟真中英文配音或团队原声）。
  - BGM：轻快且具现代科技感的电子微光风格（Ambient Tech / Modern Minimal），转入智能体决策时加入轻微科技脉冲低频。

## 二、 智能体（AI Agent）核心运行链路可视化设计

在演示视频中，必须避免将智能体做成普通的“聊天框对话”，而要将其**多维协同与自主决策**的过程通过视觉动效“外显化”：

```mermaid
graph TD
    subgraph 1. 硬件与环境感知 (Perception)
        HW[Apple Watch / 传感器] -->|实时心率/睡眠/HRV 16项| HK[(Apple HealthKit)]
        USR[用户主观打卡] -->|精力/压力/身体评分+生活事件| SD[(SwiftData 本地持久化)]
    end

    subgraph 2. 本地确定性分析与质量守门 (Gatekeeping)
        HK & SD --> DQC[数据质量计算器<br>7天有效日≥4 / 28天基线≥14]
        DQC --> BLE[个人基线与稳健变化引擎<br>中位数/MAD去噪]
    end

    subgraph 3. 智能体核心分析与决策 (Agent Cognition & Decision)
        BLE --> FPB[健康事实包构建器<br>白名单抽取/屏蔽原始样本与底层ID]
        FPB --> AP[Agent 决策中枢<br>DeepSeek 流式推理 / 识别认知缺口]
        AP -->|发现主客观矛盾/信息缺失| QN[发起精准关键追问<br>最多1个/减少用户负担]
        AP --> SEC[本地安全与医疗门禁<br>非诊断过滤/急救拦截/低焦虑文案检验]
    end

    subgraph 4. 多模块协同与行动闭环 (Action & Memory)
        SEC -->|低风险微计划候选| CKS[(CareKitStore 行动调度)]
        CKS -->|用户二次确认| TSK[创建 3-5 天微计划与每日日程]
        TSK -->|执行/跳过/反馈| EVAL[多维双向评估引擎<br>客观指标 vs 主观感受 vs 完成率]
        EVAL -->|沉淀个人策略| MEM[(我的有效方法库)]
    end
```

### 视频视觉特效呈现方式（HUD 动效卡）：
当视频播放到“AI 助手问答”时，屏幕右侧或下方同步浮现**毛玻璃半透明 Agent 运行监测面板**：
1. **[感知面板]**：绿色指示灯亮起，闪烁显示 `读取28天基线(HRV 42ms) | 捕获今日压力评分(4/5) | 捕获事件(加班到深夜)`。
2. **[事实包组装]**：显示 `白名单聚合事实包构建完成 (隐私脱敏 100%)`。
3. **[推理与安全守门]**：显示 `正在流式推理... 触发安全规则：非医疗诊断过滤通过，识别恢复缺口，推荐低风险微计划`。
4. **[协同调用]**：显示 `唤起 CareKitStore：注入“22:30 睡前准备”计划候选`。

这种呈现方式能直接让评委确认：**这是一个深度融入移动系统、遵循安全规范的具身化专业智能体，而非简单的网页 API 搬运工。**

## 三、 实物原型拍摄规范与场景设置

根据大赛“硬件作品的演示视频须包含实物原型的实际运行画面”的明确要求，本视频设计了三组实物实拍镜头：

1. **实物出镜 A：穿戴监测镜头**
   - **镜头内容**：用户手腕佩戴 Apple Watch（背面绿色光学心率传感器发光特写），正在办公室伏案工作或进行轻度伸展。
   - **作用**：直观交代数据感知硬件源头，体现真实工作与生活场景。
2. **实物出镜 B：软硬件联动与同步镜头**
   - **镜头内容**：用户将 Apple Watch 靠近 iPhone，手机上的 HealthKit 立即同步体征数据，知衡 App 界面实时刷新“今日健康状态”。
   - **作用**：向评委证明软硬件一体化数据管道的真实畅通，消除“纯界面贴图”质疑。
3. **实物出镜 C：真机操控手持特写镜头**
   - **镜头内容**：大光圈景深微距镜头，手持 iPhone 15/16 Pro 真机，手指在知衡 App 上滑动浏览 HRV 趋势图、点击完成微计划打卡、触发 AI 流式对话。
   - **作用**：展示产品的真机实际运行流畅度、SwiftUI 原生质感与高质量交互细节。

## 六、 视频后期剪辑与包装制作指南

### 1. 剪辑软件推荐与工程轨道规划
- **剪辑工具**：剪映专业版（CapCut Desktop）、Final Cut Pro 或 Adobe Premiere Pro。
- **时间线轨道结构（自上而下）**：
  - `Track 4 [顶层-字幕与贴纸]`：旁白双语中文字幕、赛事信息浮标、专业名词划线。
  - `Track 3 [特效-HUD动效层]`：半透明 Agent 决策面板、数据流发光线条、步骤数字标圈。
  - `Track 2 [画面-实拍与录屏]`：手机无损录屏（套用 iPhone 16 Pro 钛金属模型框架）+ 实物实拍镜头（画中画缩放切换）。
  - `Track 1 [底层-背景板]`：微动态深色科技质感渐变背景（避免纯黑，使用知衡主色系 `#18324A` 与 `#2A7A78` 的暗光流动）。
  - `Audio 1 [旁白轨]`：经过降噪、压限、EQ 优化的解说人声（电平维持在 -6dB 至 -3dB）。
  - `Audio 2 [音效轨-SFX]`：科技打字音、数据扫描音、打卡清脆声、转场风声。
  - `Audio 3 [BGM轨]`：背景音乐（有人声解说时音量压至 -20dB，过渡时升至 -12dB）。

### 2. 视觉包装设计规范
- **字体规范**：
  - 标题与突出强调：苹方黑体加粗（PingFang SC Semibold / Bold）或 思源黑体。
  - 旁白字幕：思源黑体 Medium，字号适中，白色加微弱外发光/半透明深色黑底，确保在任何背景下清晰易读。
- **色彩规范（严格统一于知衡设计系统）**：
  - 科技主深色（Navy）：`#18324A`
  - 活力青绿（Teal，用于高亮 Agent 决策与客观提升）：`#2A7A78`
  - 温暖橙黄（Orange，用于主观感受与生活情境）：`#E8874A`
  - 纯净白（White）：`#FFFFFF`
- **外壳模型包装（Mockup）**：
  - 屏幕录屏建议套入带微弱阴影和环境反射的 iPhone 16 Pro 钛金属深空黑外壳，避免直接放纯矩形录屏，极大提升作品质感与视觉高级感。

### 3. 硬件原型拍摄设备与布光建议
- **设备**：任意近两年发布的手机（开启 4K 60fps 电影效果模式）或单反/微单（搭配 35mm 或 50mm 大光圈镜头）。
- **光线**：
  - 主光：侧前方 45 度柔光（暖白光，照亮手腕与桌面）。
  - 轮廓光：斜后方一盏冷色小补光灯，打在 Apple Watch 金属边缘与 iPhone 边框上，营造科技金属质感。
- **稳定**：使用手机三脚架或桌面云台，杜绝手部抖动，确保画面沉稳专业。
