## 强制工作规则

后续进行任何开发、设计或测试工作时，必须遵守以下顺序：

1. 开始前阅读 `AGENTS.md`、最新每日日志和开发执行步骤。
2. 当天日志不存在时创建 `开发日志/YYYY-MM-DD.md`。
3. 一次只推进一个能够独立验收的任务编号。
4. 修改完成后进行与风险相匹配的验证。
5. 验证通过后更新实施总方案中的任务状态。
6. 每完成一项立即更新当天日志的完成事项、待办、风险和下一步。
7. 没有验证和当天日志记录的工作不视为完成。

如果实际实现需要改变已经确定的产品范围，应先在当天日志中记录原因和影响，再更新方案，不能悄悄改变方向。
